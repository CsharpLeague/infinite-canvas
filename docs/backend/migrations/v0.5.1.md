# v0.5.1 数据库升级

后端启动时会通过 GORM `AutoMigrate` 自动补齐本次字段。仅在生产环境禁止自动迁移时，需要按实际数据库执行下面对应的一组语句。

本次只调整 `video_tasks` 表：

- 新增 `context_ir_task_id`：保存 MiniMax H3-Context-IR 预审任务 ID，并建立索引。
- 新增 `enhanced_prompt`：保存预审返回、实际用于生成的增强提示词。

渠道协议、模型定价和自定义分辨率仍保存在现有 `settings` 表 JSON 中，不需要修改表结构。

## SQLite

```sql
ALTER TABLE video_tasks ADD COLUMN context_ir_task_id TEXT;
ALTER TABLE video_tasks ADD COLUMN enhanced_prompt TEXT;
CREATE INDEX IF NOT EXISTS idx_video_tasks_context_ir_task_id
    ON video_tasks (context_ir_task_id);
```

## MySQL

```sql
ALTER TABLE video_tasks
    ADD COLUMN context_ir_task_id VARCHAR(255) NULL,
    ADD COLUMN enhanced_prompt LONGTEXT NULL,
    ADD INDEX idx_video_tasks_context_ir_task_id (context_ir_task_id);
```

## PostgreSQL

```sql
ALTER TABLE video_tasks ADD COLUMN context_ir_task_id VARCHAR(255);
ALTER TABLE video_tasks ADD COLUMN enhanced_prompt TEXT;
CREATE INDEX IF NOT EXISTS idx_video_tasks_context_ir_task_id
    ON video_tasks (context_ir_task_id);
```

执行前应先备份数据库。以上语句用于尚未添加这些字段的旧版本数据库，不要在同一数据库重复执行 `ALTER TABLE ... ADD COLUMN`。
