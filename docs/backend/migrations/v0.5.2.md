# v0.5.2 数据库升级

后端启动时会通过 GORM `AutoMigrate` 自动创建本次新增表。仅在生产环境禁用自动迁移时，需要在升级服务前按实际数据库执行下面对应的一组语句。

本次新增：

- `canvas_skills`：保存 Skill 指令、参考资料和画布工具白名单。
- `canvas_agent_runs`：保存服务端 Agent Run 状态、协议和待执行工具。
- `canvas_agent_events`：保存可断线续传的 SSE 事件。

Run 访问凭证只保存 SHA-256 哈希 `token_hash`，不保存明文。

## MySQL

```sql
CREATE TABLE canvas_skills (
    id VARCHAR(191) NOT NULL,
    slug VARCHAR(191) NOT NULL,
    name VARCHAR(255) NOT NULL DEFAULT '',
    description TEXT NULL,
    category VARCHAR(255) NOT NULL DEFAULT '',
    icon TEXT NULL,
    placeholder TEXT NULL,
    instructions LONGTEXT NULL,
    files LONGTEXT NULL,
    allowed_tools JSON NULL,
    status VARCHAR(64) NOT NULL DEFAULT 'draft',
    sort BIGINT NOT NULL DEFAULT 0,
    created_at VARCHAR(64) NOT NULL DEFAULT '',
    updated_at VARCHAR(64) NOT NULL DEFAULT '',
    PRIMARY KEY (id),
    UNIQUE KEY idx_canvas_skills_slug (slug),
    KEY idx_canvas_skills_category (category),
    KEY idx_canvas_skills_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE canvas_agent_runs (
    id VARCHAR(191) NOT NULL,
    owner_id VARCHAR(191) NOT NULL DEFAULT '',
    token_hash VARCHAR(64) NOT NULL DEFAULT '',
    session_id VARCHAR(191) NOT NULL DEFAULT '',
    canvas_id VARCHAR(191) NOT NULL DEFAULT '',
    skill_id VARCHAR(191) NOT NULL DEFAULT '',
    model VARCHAR(255) NOT NULL DEFAULT '',
    channel_id VARCHAR(191) NOT NULL DEFAULT '',
    user_channel_id VARCHAR(191) NOT NULL DEFAULT '',
    status VARCHAR(64) NOT NULL DEFAULT '',
    phase VARCHAR(191) NOT NULL DEFAULT '',
    step BIGINT NOT NULL DEFAULT 0,
    max_steps BIGINT NOT NULL DEFAULT 0,
    input LONGTEXT NULL,
    protocol LONGTEXT NULL,
    tools LONGTEXT NULL,
    pending_tool_calls LONGTEXT NULL,
    output LONGTEXT NULL,
    error LONGTEXT NULL,
    created_at VARCHAR(64) NOT NULL DEFAULT '',
    updated_at VARCHAR(64) NOT NULL DEFAULT '',
    PRIMARY KEY (id),
    KEY idx_canvas_agent_runs_owner_id (owner_id),
    KEY idx_canvas_agent_runs_token_hash (token_hash),
    KEY idx_canvas_agent_runs_session_id (session_id),
    KEY idx_canvas_agent_runs_canvas_id (canvas_id),
    KEY idx_canvas_agent_runs_skill_id (skill_id),
    KEY idx_canvas_agent_runs_channel_id (channel_id),
    KEY idx_canvas_agent_runs_user_channel_id (user_channel_id),
    KEY idx_canvas_agent_runs_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE canvas_agent_events (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    run_id VARCHAR(191) NOT NULL DEFAULT '',
    type VARCHAR(191) NOT NULL DEFAULT '',
    data LONGTEXT NULL,
    created_at VARCHAR(64) NOT NULL DEFAULT '',
    PRIMARY KEY (id),
    KEY idx_canvas_agent_events_run_id (run_id),
    KEY idx_canvas_agent_events_type (type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## SQLite

SQLite 环境直接启动新版后端，由 `AutoMigrate` 创建新表即可。

## PostgreSQL

PostgreSQL 环境建议直接启动新版后端执行 `AutoMigrate`；如生产环境禁用自动迁移，可依据上方字段将 MySQL 的 `JSON` 改为 `JSONB`、`LONGTEXT` 改为 `TEXT`、自增主键改为 `BIGSERIAL`。

执行前应先备份数据库。以上语句只用于尚未创建这些表的数据库，不要重复执行。
