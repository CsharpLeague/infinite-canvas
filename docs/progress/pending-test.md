# 待测试

- 全局视频清晰度的新配置默认值与缺失配置回退值调整为 480p；新建空视频节点会根据当前模型写入其支持的默认分辨率，例如 MiniMax-H3 使用 768P、Kling 使用 720p，其他普通视频模型默认 480p；已有节点和用户已经明确保存的选择保持不变。
- Sub2API 文本代理会把 Agent 的 assistant `tool_calls` 和 tool 结果正确转换为 Responses 的 `function_call` / `function_call_output`，并保留相同 `call_id`，避免工具执行后的下一轮请求因协议链断裂返回 502。
- 画布 Agent 文本请求改为兼容 SSE 流式响应与普通 JSON，降低长耗时模型被代理层 524 截断的概率；同时限制会话历史总体积，并在工具已执行后的总结请求超时时保留画布结果、避免重复执行。
- 旧版画布中缺少 `protocolMessages` 或 `agentState` 的 Agent 会话会在加载和执行时自动补齐默认值，保留原有对话且不再出现 `input.protocolMessages is not iterable`。
- 有内容的音频节点工具栏会显示“存素材”，保存后以音频类型进入“我的素材”，并保留云存储键、文件类型、大小和时长信息；音频素材卡显示标题、波形、格式和时长，便于区分不同音频。
- 视频上游任务完成后会先保存完成状态和临时媒体地址，前端无需等待视频及首尾帧上传云存储即可停止转圈；云端上传随后完成并替换地址，失败时保留临时地址和手动上传能力。
- 视频节点切换清晰度后，预计算力点会立即按所选分辨率的自定义档位重新计算，不再受画面尺寸中的数字干扰。

## 模型算力点

- 管理后台模型计费支持“固定扣费”和“视频按秒”两种模式；视频模式可按模型动态新增或删除分辨率费率，例如 MiniMax-H3 只配置 768P、2K。
- 视频任务由后端从实际请求解析分辨率和秒数，按标准化后的分辨率名称精确匹配“对应费率 × 秒数”预扣；未配置或费率为 0 时回退到固定点数，上游失败继续按实际预扣点数返还。
- Agnes 请求会根据 `num_frames` 和 `frame_rate` 推算计费秒数；画布常规 multipart 视频请求读取 `resolution_name`、`size`、`seconds` 或 `duration`。
- 画布视频节点和视频配置节点按当前分辨率、尺寸与秒数实时显示预计算力点，不再只显示固定扣费字段。

## Agnes Video V2.0 渠道

- 管理后台渠道类型新增 Agnes；推荐使用 `https://apihub.agnes-ai.com/v1` 和模型 `agnes-video-v2.0`。
- 视频创建使用 `/v1/videos`，轮询优先使用创建响应中的 `video_id` 请求 `/agnesapi`，并从 `metadata.url` 读取最终视频。
- Agnes 协议支持单图参考和多关键帧参考；公开渠道与登录用户同步的本地渠道会保留协议字段，避免仅依赖模型名判断。

## 画布节点参考

- 节点生成面板会以缩略图展示当前连接的图片、视频、音频和文本参考，并标记首帧、尾帧或实际引用编号。
- 悬停参考素材可预览内容，点击缩略图可定位来源节点；点击右上角删除会直接移除对应连线，避免存在容易误解的临时排除状态。
- 缩略图使用更圆润的横向小卡片样式；点击添加按钮可选择画布素材节点并自动建立连线。
- 从“我的素材”拖入图片时会在原图地址缺失时使用封面地址，并根据云存储键解析真实图片 URL，避免创建空图片节点。

## 画布媒体播放器

- 视频和音频节点接入 Media Chrome，替换浏览器默认控件。
- 视频播放器提供中央播放按钮、悬停底部控制层、进度、时间、音量和全屏控制；音频播放器使用统一的播放、时间、进度和静音控件。
- 播放器交互与画布拖动、缩放事件隔离。
- 播放、暂停、静音、恢复音量、进入全屏和退出全屏等播放器提示统一显示为简体中文。
- 播放器控制按钮不再显示悬停提示浮层，同时保留中文无障碍标签。

## 画布异步任务状态

- 视频任务改为先保存客户端任务占位记录，再请求上游创建任务，避免画布轮询早于任务落库后长期停留在 `queued / 0%`。
- 上游创建成功后使用同一客户端任务 ID 更新正式任务信息；创建失败、响应异常或缺少任务 ID 时同步把占位任务标记为失败。
- 图片和音频原本已经采用先落库后执行的任务生命周期，继续保持现有逻辑。
- 图片生成结果无论返回 URL 还是 Base64，都会自动转存当前云存储；任务只保存云端 URL 和脱敏响应摘要，避免 MySQL `TEXT` 被超长 Base64 撑满后永久停在 10%。
- 上游图片结果返回后立即以临时地址同步到画布，云存储转存继续在后台执行；上传成功后自动替换为云端地址，失败后才显示手动“上传云端”。
- 视频生成完成后自动下载并转存当前云存储，再以云端 URL 完成任务；上传失败时任务明确标记失败。
- 图片和视频节点移除手动“上传至云存储”操作，避免对已自动转存的生成结果重复上传。

## 模型渠道类型与结果兼容

- 管理后台渠道类型支持通用 OpenAI、New API、Sub2API、火山方舟和 KIE。
- 文本模型继续使用最小文本请求测试；图片、视频和 KIE 模型改为非收费的连接、鉴权、模型或配置检查。
- Sub2API 文本渠道使用 Responses 接口测试。
- 图片结果解析兼容标准 `data[].url`、`data[].b64_json`，以及常见的 `images`、`result`、`output`、`image_url`、`base64` 嵌套返回，最终保持现有生图结果结构。
- 图片生成与编辑接口兼容 SSE 响应头缺失或错误的 New API 中转返回，可从 `image_generation.completed` / `image_edit.completed` 事件中提取 Base64 图片。
- Images API 默认明确请求 `response_format: url`，仅在用户开启 Base64 返回时改为 `b64_json`；流式传输保持默认关闭。
- AI 调用日志会脱敏完整或被截断的超长 Base64 图片内容，避免返回详情被图片数据占满。
- 火山引擎 TOS 存储自动使用 S3 Endpoint 和 VirtualHostStyle 请求，修复上传及容量统计的 `InvalidPathAccess` 错误；其他 S3/R2 配置继续使用原路径方式。

## 火山方舟视频生成

- Seedance 视频渠道继续使用项目统一的 `/videos` 创建与 `/videos/{id}` 查询入口，后端转发到火山方舟官方 `/api/v3/contents/generations/tasks`。
- 画布的通用 multipart 请求会转换为方舟官方 JSON `content` 结构，包含文本提示词、比例、分辨率、时长、音频生成开关、首尾帧以及图片、视频、音频参考素材。
- 已经符合方舟官方格式的 JSON 请求保持原样直通；创建结果 `id`、任务状态和 `content.video_url` 继续转换为项目现有视频任务结果。
- 任务完成响应会明确读取火山方舟嵌套的 `content.video_url`，避免上游已返回视频但画布提示“没有返回视频地址”。
- 火山方舟视频创建请求默认发送 `return_last_frame: true`，任务完成后读取并转存 `content.last_frame_url`，供连续视频节点引用上一段尾帧。
- 本地图片文件可转换为 Base64 Data URL；参考视频和音频需先上传云存储并提供可公开访问的 URL。

## 文本模型与画布助手
- 创作 Agent 同时解析 Chat Completions 与 Responses 的文本、`output_text` 和 `function_call` 返回，Sub2API 返回 HTTP 200 时不再因缺少 `choices[0].message` 被误判为请求失败。

- New API 和通用 OpenAI 渠道继续使用 `/chat/completions`；Sub2API 文本渠道会由后端自动转换到 `/responses`。
- Sub2API 转换支持系统提示词、连续对话以及画布图片引用，助手可同时解析 Chat Completions 和 Responses 的流式文本事件。
- 画布助手已支持文本问答、生图、选中节点引用、历史会话、重试以及把文本或图片插入画布，界面移除过期的“未开发”标记。
- 视频生成常见上游错误会转换为直白中文，覆盖参考图真人审核、内容安全、API Key、额度、限流、超时、熔断和网络错误；原始详情继续保留用于排查。

## PM2 部署

- 新增 PM2 生产配置，同时托管 Go 后端和 Next.js standalone 前端。
- 新增 Linux 一键部署脚本，负责后端编译、Bun 依赖安装、前端构建、静态资源复制及 PM2 平滑重载。
- 新增 Linux dist 免编译发布包脚本，服务器保留现有 `.env`，只需覆盖程序文件并执行 `start.sh`。

- 新增 PM2、Nginx、HTTPS、环境变量和后续更新说明。
- MySQL 唯一索引字符串字段明确使用 `VARCHAR(191)`，避免触发 `Error 1170`，同时保持系统设置、画布数据和日志等内容继续使用大文本字段。
## 反推提示词图片输入优化

- 反推提示词优先向视觉模型传递公开云存储 URL，避免把 4K 图片完整编码进 Chat Completions 请求。
- 无公开地址时自动压缩图片并使用 Base64 兜底。
- 上游返回 502 时显示中文原因，并提示更换支持图片理解的模型渠道。
- 文本模式配置节点不再被视频高级参数过滤掉图片引用；请求发送前会核对 composer 中引用的图片是否真实进入多模态消息，缺失时终止请求并提示检查节点连线。

## 视频结果恢复与云存储兜底

- 视频上游生成成功后，即使自动上传云存储失败，也会保留原始视频地址并将结果同步到画布。
- 未同步结果的视频节点可点击“同步结果”查询原任务，不会重新生成或再次扣费。
- 自动上传成功的图片和视频不显示“上传云端”；没有云存储键的结果显示“上传云端”，可手动补传。
- 已完成的视频任务保留 24 小时，便于页面刷新、网络中断后恢复结果。
- 直接拖入或上传到画布的音频、视频优先写入云存储；历史本地媒体作为火山视频参考时会在提交前自动补传云端。
- 火山参考媒体没有公网 URL 时返回具体中文原因，不再显示笼统的“AI 接口请求失败”。
- 火山方舟仅连接参考音频时会在提交前提示必须同时连接图片或视频，避免产生无效上游请求。
- 视频任务返回的首帧、尾帧和视频文件会分别转存云端；视频节点连接到下一个视频节点时，默认使用上一段视频的尾帧作为下一段首帧。
## 视频节点引用模式

- 视频节点连接到下一视频生成节点时，有尾帧则默认作为下一段首帧引用。
- 引用缩略图会显示当前使用的是“尾帧”还是“视频”，点击左上角标识可在两种模式间切换。
- 显示的缩略图、保存的节点配置和实际生成请求统一使用同一引用模式。
- 视频采用尾帧引用模式时，输入框 `@` 候选会将其作为图片编号并标记“尾帧”；切换为整段视频后恢复为视频编号，确保候选、提示词和请求资源类型一致。
- 视频连线默认选择尾帧时，将尾帧作为普通参考图片发送，可与角色图片和参考音频同时使用；仅在视频设置中明确指定首帧或尾帧时发送火山首尾帧字段。

# 火山方舟虚拟人像素材

- 火山方舟渠道可单独配置虚拟人像素材 API Key；未配置时前端不显示入库入口。
- 图片素材支持“入库为虚拟人像”，并显示处理中、虚拟人像、审核失败状态。
- 同一用户、渠道和源图片使用指纹去重，不会重复创建火山素材。
- 已可用的虚拟人像拖入画布后，仅火山视频模型发送 `asset://asset_id`；其他视频模型忽略素材 ID，直接发送原公网 URL。
- Grok 视频前端仅提供 5、10、15 秒三个固定选项且不显示自定义秒数输入；Grok 1.0 请求与 APIMart 后端适配仍按接口限制处理，Grok 1.5 Preview 限制为最多 15 秒且最多传入一张参考图，避免越界时返回 `Value must be within the specified range`。
- 虚拟人像与当前视频渠道不一致时会阻止提交并显示中文提示。
- 审核错误会转换为便于理解的中文原因；失败素材允许重新入库。
- 线上 MySQL 需执行 `docs/deployment/mysql-virtual-portraits.sql`。
- 火山素材接口已改用 `ark.cn-beijing.volcengineapi.com` OpenAPI 与 AK/SK HMAC-SHA256 签名；需重新填写渠道的素材 Access Key ID 和 Secret Access Key。
- 删除已入库虚拟人像时会先调用火山 `DeleteAsset`，远端删除成功后才移除本地素材与任务记录；需验证成功和权限不足两种场景。
- 管理后台设置页和画布前端配置弹窗的非登录密钥框已禁用浏览器自动填充，并添加主流密码管理器忽略标记；登录和用户密码表单保持原有自动填充语义。
- 画布左侧“虚拟人像”分类新增“上传人像”入口，上传后自动保存到我的素材并提交火山审核；图片节点工具栏新增“入库人像”，可自动上传云存储、保存素材并同步处理中/可用/失败状态。
- 素材类型选项改为单行横向滚动且禁止文字换行，避免窄侧栏中被压成竖排。
- 管理后台通过协议字段直接控制火山素材鉴权表单的挂载，并使用独立状态捕获密码输入框的真实值；保存时将素材 AK/SK 明确合并到渠道数据，并校验素材 Access Key ID 与 Secret Access Key 必须成对填写。保存后会保留当前页面中的凭证状态，避免后续操作丢失素材凭证。升级后需重新填写一次这两个字段。
- 编辑已有渠道时，素材 AK/SK 区域改由独立协议状态控制首次渲染，避免生产构建中表单字段尚未挂载导致火山方舟鉴权区域被隐藏。
- 虚拟人像入库会把 `server:`、`/api/files/{id}` 和 `/api/files/{id}/content` 图片解析为存储对象的公网 URL，并校验对象所有者；前端不再把相对文件地址误当作公网地址，创建失败时直接显示后端返回的中文原因。
- 画布节点和“我的素材”中已经带有 `server:` 存储键的图片，入库虚拟人像时直接读取对应的云存储公网 URL，不再通过图片代理重复下载和上传。
- 虚拟人像审核可用后，画布节点工具栏隐藏“入库人像”操作；从“我的素材”删除虚拟人像时，会依次删除火山素材、虚拟人像任务记录、云存储对象和本地素材，并提示现有画布引用将失效。
- 画布左侧“资产 → 我的素材”卡片新增悬停删除按钮，普通素材执行原有安全清理，虚拟人像复用火山素材、任务记录、云存储对象和本地素材的完整删除流程。
- 支持音频生成的视频模型默认开启“生成与视频同步的 AI 音频”；配置存储执行一次升级，将旧版本遗留的全局默认关闭值调整为开启，节点自身明确保存的关闭状态继续保持关闭，升级后用户仍可再次手动关闭。

## MiniMax 官方视频渠道

- 管理后台新增 `MiniMax 官方` 渠道类型，渠道地址可填写 `https://api.minimaxi.com`，模型固定使用 `MiniMax-H3`。
- 创建与查询任务分别适配 Video Generation V2 官方接口，任务状态和视频地址转换为项目统一格式。
- 支持文生视频、首帧、尾帧、首尾帧以及参考图片、视频、音频；首尾帧与多模态参考模式互斥。
- MiniMax 素材仅发送公网 HTTP(S) 地址；本地文件未上传云存储时会返回明确提示。
- 正式生成前先调用 H3-Context-IR 对相同的多模态上下文做异步预审和提示词增强；敏感或失败时不创建正式视频任务、不扣视频生成算力点，成功后使用 `content.prompt` 提交生成。
- 视频任务响应返回 `context_ir_task_id`、`context_ir_status` 和 `enhanced_prompt`，前端任务对象可查看并保存实际用于生成的增强提示词。
- H3-Context-IR 的任务提交和每次结果轮询都会写入 AI 调用日志；前端会将 `input new_sensitive`、`input text sensitive` 转换为中文安全审核提示。

## 字字动画视频渠道

- 管理后台新增 `字字动画` 渠道类型；渠道地址填写 `https://www.zizidonghua.com`，创建任务使用 `/v8/videos/generations`，查询任务使用 `/v8/videos/generations/{task_id}`。
- 画布视频参数会转换为该渠道要求的 JSON，并将参考图转换为顶层 `reference_images`；仅传递公网 HTTP(S) 地址，不传火山素材 ID 或本地文件。
- 选中字字动画渠道的模型后，视频设置隐藏清晰度和像素尺寸，改为横屏、竖屏、方形三个画面比例；请求不传 `resolution`，仅传 `aspect_ratio`，清晰度由 `zzdh-*-480p/720p/1080p/2k` 模型自身决定。
- 创建与查询响应支持递归解包 `data.data`，将 `NOT_START`、`IN_PROGRESS` 等状态映射为项目任务状态，并解析百分比进度、`fail_reason`、内层错误和最终视频地址，保证后台轮询不会因未知状态提前停止。
- `dispatched`、`accepted`、`started`、`generating` 等上游中间状态统一映射为 `processing`；待轮询查询兼容修复前已保存的原始状态，使现有任务重启后也能恢复查询。
- 前端为 `MiniMax-H3` 提供 768P/2K、官方六种画面比例、4 至 15 秒及 AIGC 水印设置。
